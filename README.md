# lampa-plugins

Personal plugins for [Lampa](https://github.com/yumata/lampa).

## tuner.js
Quality-of-life defaults: parser timeout 30s, jackett interview "all".

Install in Lampa: Настройки → Расширения → Добавить плагин →
`https://raw.githubusercontent.com/facepalmua/lampa-plugins/main/tuner.js`
